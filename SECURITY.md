# Security reporting

Report suspected vulnerabilities privately to [mihir@ostrich-ai.com](mailto:mihir@ostrich-ai.com). Include repository, source revision, affected boundary, reproduction using synthetic data, observed impact and suggested mitigation. Do not post credentials, personal data, exploit details or protected source in public issues.

This contact route is maintained by the founder. No response SLA, supported-version guarantee or bounty is promised by this document.
